# Static//Lab

A deliberately overbuilt static-site demo for GitHub Pages. No server runtime and no framework dependencies.

Features include responsive layout, async JSON loading, search/filter/sort, canvas animation, interactive node dragging, localStorage persistence, URL-backed state, keyboard command palette, theme persistence, PWA manifest, and a service worker for offline caching.

## Publish on GitHub Pages

Repository Settings → Pages → **Deploy from a branch** → `main` → `/ (root)` → Save.

Expected project-site URL:

`https://silascroe.github.io/testing-1/`
